# Frostbite 2.2.5 简体中文固定预设版 r2

安装包：Frostbite-2.2.5-CHS-NoMCM-r2.zip，使用 MO2 安装并覆盖旧 Frostbite 的同名文件，插件仍为 Frostbite.esl。

最终预设：凉爽 0.0075、寒冷 0.015、严寒 0.05；每 5 秒检测；取暖动画开启。关闭本模组的 MCM 设置入口及旧快捷键调节，保留体温条，不影响其他模组的 MCM。

修正冰抗扣值公式、减益清理和取暖动作退出。实际游戏文字已重新汉化，源码及说明在包内。

四份脚本通过 Windows 编译。源码/ESL 和下载后的实际 PEX/ZIP 已分别复核；配置脚本无参数写入和 RegisterMod 调用，保留自身菜单注销调用。没有进行 Skyrim 双机游戏实测。
