# STR 1.8.4 / SE 1.6.1170 尸体死亡流程与告示板接收保护修订

基于已编译的 loot1 累积源码，保留其 NPC 库存计数修正、装备/丢物/家具与告示板r1脚本。用户报告同一尸体等待后装备数量可恢复；本包未另加库存延迟优化。

尸体：远端动作快照原来可能直接把活着的本地副本标成死亡，导致死亡通知按IsDead跳过KillImpl。现在对远端非玩家NPC，活着/濒死/死亡三态之间的转换保留本地原生流程的状态位，仍播放完整动作队列。已由服务器确认死亡、场景和3D就绪的NPC允许运行濒死至死亡的原生更新及位置更新，避免等到完全死亡才开启处理的循环条件。保留玩家死亡、复活以及特殊生命状态原路径。本包不执行自动resurrect/kill，不重置尸体或背包。

告示板：补齐普通容器快照和库存增量的接收端排除，防止旧登记或在途消息覆盖专用告示。告示发布身份改用所属任务实例编号，避免依赖已进入容器的告示引用能否取得世界句柄。仍需日志确认本次联机空板是否由这些路径触发，不能宣称已完全兼容。此前r1 ESP与18个脚本源码不变。

上述原生语义只按现有源码及CommonLibSSE参考，未通过IDA/Ghidra或本地Skyrim运行核验；用户已授权源码尝试。必须完成真实Windows编译及103项测试（保留原99项，新增4项纯生命状态数据测试）、18个PEX编译、四程序检查、两轮源码比较后才交付。所有游戏效果需要双人复测。

安装：双方客户端替换SkyrimTogether.exe、EarlyLoad.dll；服务器替换STServer.dll、SkyrimTogetherServer.exe；四件必须同版，标识coopfix4g-corpse4-missives2r2-loot1。已装r1兼容ESP/脚本继续使用；未装则在MO2安装MissivesCompat，保留原Missives.esp和汉化，兼容ESP勾选排在后面。保留原配置、UI及资源。

测试：先正常击杀新NPC，客机直接搜索，测试普通攻击与终结动作、NPC卸载重载及不同先入区顺序；回归倒地/死亡字幕/装备计数。请先记录未经控制台改动的异常，再将控制台resurrect后kill作为对照，记录时间。告示板先离线看见告示，再联机，双方比较内容、接取后移除、仅接取者获得信件/任务。异常时提供双方本次tp_client.log与STServerOut.log及操作时间。服务端/客户端诊断都保留。
