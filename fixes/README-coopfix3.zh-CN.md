# STR 1.8.4 / SE 1.6.1170 coopfix3 测试候选

基于官方 tag v1.8.4 / 54b3a858e228dc8807ed65bc3f9ac3c3f81b610d 及其四个精确子模块，不混入 dev。包含上一版 coopfix2 的全部掉落拾取确认、同时拾取防重复、临时 NPC 身份恢复、等待模型时尸体状态/搜刮同步，以及禁止玩家间潜行偷窃。

## 本次新增

- 家具战斗恢复：每 500ms 只检查拥有 LocalComponent、且引擎未标记 remote 的 NPC。必须存活、模型/动画图/区域就绪、没有场景、正在战斗、有活着的战斗目标、GetSitState==3，且 occupiedFurniture 解析到真正的 FURN 家具引用。持续满足 2 秒后调用原生 EvaluatePackage，再等 2 秒若仍满足则只发送一次 ForceFurnExit。家具、引用 handle 或控制权 epoch 改变会重新计时；退出战斗或失去资格会取消；加载期间不处理。不会给 NPC 强加仇恨，不开启远端 AI，不删除椅子、不清坐姿位、不复活 NPC。
- 恢复的退出事件使用现有 ActionEvent 上行、所有权验证和广播；原有服务器回放缓存已把 ForceFurnExit 识别为退出事件，后来进入区域的玩家不会从这条缓存重放旧坐姿。接收端补上已传输的 targetEventName。
- 新日志 STR furniture hit audit / observed / reevaluate / exit，用于区分坐姿、真实家具占用、AI 控制端、战斗目标和任务场景。accepted=true 仅表示动画事件被接受，不能当成起身成功。
- 掉落物代理持有引擎引用，等待模型出现后只进行一次位置/旋转对齐；最多三次启用动态物理并小幅向下唤醒，保留地面碰撞。原持有者真实掉落引用不做这些物理操作。销毁顺序先 Disable/Delete，再释放持有引用。
- 修复自定义掉落协议把弧度旋转当整数位置压缩的问题，完整保留小数/负数角度；服务器拒绝非有限角度。协议版本改为 v1.8.4-coopfix3，客户端和服务器必须匹配。

## 重要边界

此为根据源码实现的候选，并非已确认修复所有 NPC 问题。未做 IDA/Ghidra 和本地双人游戏验证。occupiedFurniture 布局参考 CommonLibSSE-NG 并增加偏移断言；并未把 CommonLib 引入项目。偏移断言证明编译布局，不证明游戏二进制布局。原生 Papyrus 调用、ForceFurnExit 是否完整释放家具，以及其任务副作用仍属源代码假设，用户已经授权进行此类尝试。

仅在实际战斗中坐着并占用有效家具时恢复。未进入战斗、无目标、占用引用丢失、动画坐姿但原生 sit==0、任务场景中的 NPC 会保守跳过。正常坐下却悬空的坐点/根节点位移问题没有据此保证修复；不能简单把所有 NPC 降低固定高度。掉落物没有提示的全部原因也尚未锁定。

## 编译与检查

GitHub Actions 使用 Windows 2022 / MSVC / xmake 3.1.0，目标 release、x64、skyrim_version=1.6.1170。只有实际编译链接、服务器生成配置启动检查、单元测试、PE/版本/修复标记检查、重复构建及四文件哈希检查都成功后，才会打包 candidate。预计共 55 个纯数据/协议/时序及既有测试；不把这些测试称为引擎功能测试。

## 安装

先退出两个客户端及服务器，备份原文件。在 MO2 中通过当前执行项的实际路径找到正在加载的 STR：

- 客户端 STR 目录：SkyrimTogether.exe、EarlyLoad.dll，两边都替换。
- 服务器实际启动目录：STServer.dll、SkyrimTogetherServer.exe，两件配对替换。
- 若同一目录保存客户端和服务器，则覆盖四件。保留原包资源、脚本、行为文件及配置，不把只有四件的补丁当完整 MOD 安装。Gameplay:bEnableItemDrops=true 才启用玩家掉落同步。

日志在正在启动的 SkyrimTogether.exe 相邻 logs/tp_client.log，服务器为其日志目录；MO2 以实际加载路径为准。

## 双人测试

使用保留的出错存档副本和未出错备份分别测试，不覆盖唯一存档。先在普通坐椅敌人旁连接：两人轮流先入区域、先攻击，比较战斗后 4–6 秒是否起身，交换队长再试。再检查友善 NPC 正常坐下、任务对话场景、骑马是否不受影响。记录正常坐姿悬空与战斗卡住是否分别改善，并保留两端同一次会话日志。

回归掉落物双方丢/捡、同时捡、区域重入、重连；观察是否有贴图但无名称/拾取提示、悬空或穿地。回归尸体死亡和搜刮、随机遭遇是否重复，以及玩家间潜行偷窃拦截。服务器重启后的掉落持久化不是此补丁新增能力。
