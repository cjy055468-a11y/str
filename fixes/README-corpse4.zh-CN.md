# STR 1.8.4 / SE 1.6.1170 客机同步死亡流程 corpse4 测试候选

当前优先修尸体，告示板暂停。本包基于已送测loot1，保留其装备计数修正和告示板r1，不包含未验证的告示板r2改动。

针对复现：主机击杀、客机没攻击过的NPC可能死亡后无法搜索；客机直接kill无效，resurrect后仍保持死亡姿势，随后客机再次kill才可搜索。源码显示远端动作会复制生命状态位，可能先标记死亡而使后续死亡通知的IsDead判断跳过真正的KillImpl。

修正：仅对远端非玩家NPC，动作在活着/濒死/死亡三态之间不直接改写本地生命位，由原生死亡/复活调用执行转换。完整动作队列保留。经服务器确认死亡且3D/场景/处理器有效时允许濒死和死亡原生更新，释放对应根节点位置控制，避免等到完全死亡才允许过渡的循环条件。玩家路径、特殊生命状态以及原死亡掉落拦截保留。不执行自动复活再杀死，不重置背包或清空动作队列。

源码推断尚未通过IDA/Ghidra或Skyrim运行核验，用户已授权源码尝试；复现与此路径吻合仍不代表游戏根因已完全证实。必须实际Windows构建和103项测试（保留99旧测试）、18个PEX、四程序检查和两轮源码比较成功才交付。

安装：双方客户端替换SkyrimTogether.exe、EarlyLoad.dll，服务器替换STServer.dll、SkyrimTogetherServer.exe，四件同版标识coopfix4g-corpse4-loot1。保留配置/UI/资源及现有Missives.esp、汉化和r1兼容ESP/脚本。不要混用旧程序。

重点测试：主机击杀而客机完全不攻击，客机直接搜索新尸体；对比客机击杀。覆盖普通死亡/终结动作、死亡前后切区重载、不同先入区与所有权交接，检查倒地、原位搜索、死亡字幕、衣服和装备数量。先保留未经控制台干预的日志，再记录resurrect/kill对照时间。异常请提供双方本次tp_client.log及STServerOut.log。
