# STR corpse5 装备计数修订 loot2 测试包

基于用户测试并确认“客机尸体无法搜索”已经解决的 corpse5。用户反馈同一件装备原本数量为 1，尸体上变成 2；该重复现象早于一秒状态刷新。

## 本次修改

远端 NPC 的 3D 首次就绪时，STR 原先总会清空并重装整份主机背包快照。现在先比较客机本地库存与快照，按物品和附加数据合并拆分堆栈，并核对魔法装备；若内容一致，就保留现有库存，不重复调用清空/重装。若确有差异，仍用主机快照校正。所有权交接时也用同一比较方式，避免条目顺序不同导致无意义重装。

这是针对代码路径的修正实验。重复装备是否由首次重装引起还没有游戏内证据；没有使用“一种装备最多保留一件”的硬性裁剪，因此合法的多把同款武器和不同附魔物品仍会保留。旧存档中已经多出来的物品不会被自动删除。

## 安装与测试

备份存档和原程序。双方客户端替换 `SkyrimTogether.exe`、`EarlyLoad.dll`；开服者同时替换 `STServer.dll`、`SkyrimTogetherServer.exe`。四个文件必须来自同一个 `coopfix4g-corpse5-state1s-loot2` 版本。保留现有设置、资源、Missives 插件和兼容脚本，不要混用 corpse4/corpse5 程序。

先用干净的新测试存档或未被旧版重复同步过的 NPC。击杀后确认同一装备数量没有从 1 变成 2，并在主机和客机分别检查、搜索和取走；再交换进入区域的先后顺序。已确认可搜索的尸体状态刷新逻辑仍保留。若仍重复，请提供双方这次生成的 `tp_client.log`，并指出 NPC、物品名称和两端数量。

本包源码和 Windows 构建检查通过后发布；装备计数修复尚未经过新的双人游戏实测。构建测试不能替代这个验证。
