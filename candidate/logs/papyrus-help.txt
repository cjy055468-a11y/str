Caprica Papyrus Compiler v0.3.0
Usage: Caprica <sourceFile / directory>
Note that when passing a directory, only Papyrus script files (*.psc) in it will be compiled. Pex (*.pex) and Pex assembly (*.pas) files will be ignored.

General:
  -? [ --help ]                         Print usage information.
  -g [ --game ] arg (=starfield)        Set the game type to compile for. Valid
                                        values are: starfield, skyrim, 
                                        fallout4, fallout76. (default: 
                                        starfield)
  -i [ --import ] arg                   Set the compiler's import directories.
  -f [ --flags ] arg                    Set the file defining the user flags.
  -O [ --optimize ]                     Enable optimizations.
  -o [ --output ] arg (=D:\a\str\str)   Set the directory to save compiler 
                                        output to.
  -p [ --parallel-compile ]             Compile files in parallel.
  -R [ --recurse ]                      Recursively compile all scripts in the 
                                        directories passed.
  -r [ --release ]                      Don't generate DebugOnly code.
  --final                               Don't generate BetaOnly code.
  --all-warnings-as-errors              Treat all warnings as if they were 
                                        errors.
  --disable-all-warnings                Disable all warnings by default.
  --warning-as-error arg                Treat a specific warning as an error.
  --disable-warning arg                 Disable a specific warning.
  --config-file arg (=caprica.cfg)      Load additional options from a config 
                                        file.
  -q [ --quiet ]                        Do not report progress, only failures.
  --strict [=arg(=1)] (=0)              Enable strict checking of control flow,
                                        poisoning, and more sane implicit 
                                        conversions. It is strongly recommended
                                        to enable these.
  --ignorecwd                           Do not add the current working 
                                        directory to the beginning of the 
                                        import list.

Champollion Compatibility:
  --champollion-compat [=arg(=1)] (=1)  Enable a few options that make it 
                                        easier to compile Papyrus code 
                                        decompiled by Champollion.
  --allow-compiler-identifiers          Allow identifiers to be prefixed with 
                                        ::, which is normally reserved for 
                                        compiler identifiers.
  --allow-decompiled-struct-references  Allow the name of structs to be 
                                        prefixed with the containing object 
                                        name, followed by a #, then the name of
                                        the struct.

Skyrim compatibility (default true with '--game=skyrim'):
  --allow-unknown-events arg (=1)       Allow unknown events to be defined on 
                                        non-native classes. This is encountered
                                        with some scripts in the base game 
                                        having Events that are not present on 
                                        ObjectReference.
  --allow-var-shadow-parent arg (=1)    Allow Object variable names in derived 
                                        classes to shadow properties in parent 
                                        classes.
  --allow-local-shadow-parent arg (=1)  Allow local variable names to shadow 
                                        properties in parent classes.
  --allow-local-use-before-decl arg (=1)
                                        Allow local variables to be used before
                                        they are declared and initialized.
  --allow-assign-void-method-result arg (=1)
                                        Allow void method call results to be 
                                        assigned to Objects and Bools.

Advanced:
  --allow-negative-literal-as-binary-op arg (=1)
                                        Allow a negative literal number to be 
                                        parsed as a binary op.
  --async-read arg (=1)                 Allow async file reading. This is 
                                        primarily useful on SSDs.
  --async-write arg (=1)                Allow writing output to disk on 
                                        background threads.
  --dump-asm                            Dump the PEX assembly code for the 
                                        input files.
  --enable-ck-optimizations arg (=1)    Enable optimizations that the CK 
                                        compiler normally does regardless of 
                                        the -optimize switch.
  --enable-debug-info arg (=1)          Enable the generation of debug info. 
                                        Disabling this will result in Property 
                                        Groups not showing up in the Creation 
                                        Kit for the compiled script. This also 
                                        removes the line number and struct 
                                        order information.
  --enable-language-extensions arg (=0) Enable Caprica's extensions to the 
                                        Papyrus language.
  --resolve-symlinks arg (=0)           Fully resolve symlinks when determining
                                        file paths.
