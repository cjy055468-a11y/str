# Azurite III 汉化版：移除控制能力

移除能力菜单里的“蓝宝石冥想”控制入口。保留原 Azurite 完整模组及汉化，此包作为附加补丁安装。

用 MO2 安装 ZIP，启用 AzuriteNoControl.esp，排在 Azurite Weathers III.esp 之后。无需更换 STR 程序。补丁为 ESL 标记 ESP。

补丁停止玩家别名自动发放控制能力，并通过一个隐藏清理任务，在加载游戏后对已有存档中的该能力执行移除。加载后回到游戏中等待约十秒再查看能力菜单。清理只针对“蓝宝石冥想”，不移除其他模组能力。

保留原季节触发法术、天气、气候、区域天气表、声音和图像效果。原有预设选项不由本补丁修改。移除入口后，不能再通过该能力打开 Azurite 设置菜单。

依据用户提供的汉化 ESP 生成，输入 SHA256 为 422ac34f9510649f3d3a74bdad0435bcd42a0a1dfa3a3e7172077a6d717d219a。汉化仅改名称及菜单文字，记录 ID、天气数据和脚本绑定与另一份 ESP 一致。

STR 源码支持同步该插件所覆盖的原版/DLC天气；未发现这部分需要专用天气同步补丁。原 mod 的外部脚本及资源未包含在本附件中，尚未做游戏内双端实测。季节效果若依赖月份，日期是否一致受 STR 的 Gameplay:bSyncPlayerCalendar 设置影响。
