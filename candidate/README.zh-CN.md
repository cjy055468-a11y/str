# STR 独立公告板兼容 v2

公开告示直接由服务器清单生成，显示告示不再需要启动影子任务。某块实体告示板的告示被领取后，会从所有玩家的这块板上移除；其他实体板保持独立。任务目标、阶段、报酬和任务物品均由领取者本地游戏生成、执行，不同步给其他玩家。

公开告示显示委托类别。取下后，服务器先保留该条；领取者本地任务启动成功再确认领取，届时获得原任务信件与具体目标。启动失败则释放保留，告示可重新领取。每块板最多六条未领取/保留中的告示；已领取的任务模板经过五分钟后可以发布新一轮告示，旧回执不会影响新一轮。

## 安装

1. 保留现有 STR 基础模组。将程序包 SkyrimTogetherReborn/ 中的文件覆盖到你实际启动的 STR 程序目录；主机、客机和 Windows 服务端均使用本次同版程序。若 MO2 的启动项指向某个模组目录中的 SkyrimTogether.exe，就覆盖那个目录中的程序文件。此版本保留上次确认的 r6 尸体搜索与装备去重等非公告板修复。
2. 将 STR-NoticeBoard-v2-MO2.zip 直接用 MO2 安装，使 Scripts/ 在 Data 根下，并启用新增 STRNoticeBoard.esp。加载顺序在 Missives.esp 之后。保留原 Missives.esp、汉化及正常依赖。
3. 此包完整替换旧公告板兼容插件；停用旧兼容模组，避免其脚本覆盖新版。
4. 重启游戏再连接同版服务端；不要只换脚本而保留旧 STR 程序。

## 验证范围

新 ESP 只含 264 个独立 BOOK，不覆盖原任务、城镇或导航网格记录。网络只传公告标识、领取保留与确认回执，不传任务实例内容。自动化检查覆盖多人抢同一告示、准备失败释放、租约超时、断线回执、实体板隔离和公告代次更新。编译通过不代表完成 Skyrim 双客户端游戏内测试；实机效果仍需两端验证。

## 交付与基础

源码基础为官方 54b3a858e228dc8807ed65bc3f9ac3c3f81b610d，加上已验证 r6 的非公告板改动。notice-base-preserved.json 记录了未改动的旧基础文件。新兼容代码从零实现，原 MissiveBoard 协议/服务/桥接/脚本已删除。生成器输入为用户上传的 Missives.esp，provenance 记录输入和输出 SHA256。

任务接受过程中使用标准 Papyrus API；引擎绑定注册和个人任务物品的 alias-owner 读取使用基础包已存在的地址库/布局，没有增加新的反编译地址。游戏内菜单、任务别名填充和脚本事件交付仍属于待实机验证范围。
