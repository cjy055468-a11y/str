# Frostbite 2.2.5 简体中文重制与修复 r1

基于用户提供的 Frostbite 2.2.5 原包重新翻译并编译。默认凉、冷、严寒三档降温速度为原版的 1.5 倍。

## 安装

用 MO2 安装整个 ZIP 并启用其中的 `Frostbite.esl`。这是一份完整替换包；同一配置中保留一份 Frostbite，并让本包覆盖旧版的同名文件。原有 SKSE、SkyUI 和支持中文的游戏字体仍需保留。无需增加新的 ESP，也无需替换 STR 程序。

新游戏直接使用下表默认值。旧存档第一次载入本包时，会将仍等于原版默认值的三档降温量更新一次；已有其他自定义数值会保留。此后在 MCM 中修改的设置不会被每次读档覆盖。三档滑块均可恢复到新的默认值。

| 环境 | 原版每次降温量 | 本包默认每次降温量 |
|---|---:|---:|
| 凉爽 | 0.005 | 0.0075 |
| 寒冷 | 0.010 | 0.015 |
| 严寒 | 0.025 | 0.0375 |

检测间隔仍默认为 5 秒。回温速度、食物回温量和基础伤害比例沿用原版默认值。生命惩罚默认仍然关闭。

## 修复内容

- 重新翻译 MCM、环境提示、低温效果名称、衣物与食物确认菜单；保留内部属性、事件、关键字、插件名和表单 ID。
- 修正生命、耐力和魔法扣值时的冰抗公式：零冰抗承受基础扣值，50% 冰抗减半，100% 及以上免除，负冰抗增加扣值。修正后，默认开启的耐力和魔法惩罚会在零冰抗时实际扣值。
- 停用体温系统时清理本模组的三种恢复减益，并停止本模组启动的取暖动作；读档后的更新也会清理已停用系统的残留效果。
- 补全取暖动作的按键退出处理，包括手柄移动、交互、拔出武器、跳跃和潜行；离开热源或游泳时也会退出。
- 恢复旧汉化可能遗留的空 MCM 开关、体温条引用；提升 MCM 版本，使旧存档重新生成中文页签。
- MCM 首页直接显示设置，避免请求原包没有附带的 Logo.dds 导致首页空白。

## STR 与验证范围

体温、界面和惩罚仍由本机玩家别名处理。后台任务没有任务阶段，当前 STR 会排除这类任务的同步。没有改 STR 的网络、任务或角色所有权代码。天气按通用分类读取，可沿用 Azurite 天气记录。

发布包通过 ESL 修改范围检查、四份 Skyrim PEX 编译与字节码检查，以及 ZIP 内容和哈希检查。构建验证文件包含源码提交号。**没有运行 Skyrim 双机游戏测试**；编译通过不能代替取暖动作、旧存档升级和实际联机扣值的游戏验证。

本包保留原版作者的 Frostbite 代码与界面资源。`scripts/source` 附有本次实际编译的源码。`SHA256.json` 可用于核对包内文件。
