# Frostbite 2.2.5 中文整合：关闭屏幕闪烁、体温归零扣血

直接修改上传的 Frostbite 原模组，包内沿用原来的 `Frostbite.esl`，不需要额外启用插件。

## 本次设置

- 关闭冷热切换、完全暖和时的屏幕变色与闪动反馈。保留中文文字提示、体温条和角色靠火取暖的动作。
- 体温不高于 50% 时抑制生命自然恢复，沿用 Frostbite 原有的恢复惩罚效果。
- 体温条归零时，每次 5 秒更新固定扣除 1 点生命，不受冰霜抗性、基础生命值影响。体温大于零时不扣这 1 点生命。
- 汉化剩余的三条魔法效果说明，并在中文说明中列出各自的惩罚规则。
- MCM 继续隐藏，沿用上传包的固定预设。

耐力和魔法惩罚沿用原规则：体温不高于 50% 时抑制恢复；不高于 20% 时每次更新额外扣除各自基础值的 5%，受冰霜抗性影响。

| 环境 | 每次更新的降温量 |
|---|---:|
| 凉爽 | 0.0075 |
| 寒冷 | 0.015 |
| 严寒 | 0.05 |

## 安装

退出游戏，用 MO2 将这个完整包替换原 Frostbite，或将包内文件覆盖到原模组目录。继续启用原有的 `Frostbite.esl`。STR 程序不需要替换。

实际脚本为 `scripts/_JSW_FB_HandlerScript.pex`，对应源码位于 `scripts/source`。`SHA256.json` 可核对包内文件。
