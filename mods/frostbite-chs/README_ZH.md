# Frostbite 2.2.5 简体中文固定预设版 r2

基于用户提供的 Frostbite 2.2.5 原包重新汉化并修复。按最终要求关闭 Frostbite 的 MCM 设置入口，不提供局内调整选项。保留体温系统、体温条及默认开启的取暖动画。

| 环境 | 原版每次降温量 | 本包固定降温量 |
|---|---:|---:|
| 凉爽 | 0.005 | 0.0075 |
| 寒冷 | 0.010 | 0.015 |
| 严寒 | 0.025 | 0.0500 |

凉爽、寒冷为原版 1.5 倍；严寒按用户后续指定为 0.05，是原版 2 倍。每 5 秒检测一次，取暖动画开启，生命惩罚关闭。其他设置采用原包默认值。初始化及读档时应用固定预设，旧存档的 MCM 参数也会恢复为本包设置。关闭旧的体温条切换快捷键，避免通过旧快捷键修改显示参数。

## 安装

用 MO2 安装整个 ZIP 并启用 `Frostbite.esl`，让本包覆盖旧 Frostbite 的同名文件。保留原有 SKSE、SkyUI 和中文字体。无需新增 ESP，无需替换 STR 程序。

该包只注销 Frostbite 自己的 MCM 菜单。旧存档中若 SkyUI 尚有缓存，脚本会请求移除该菜单；缓存页的全部旧按钮和滑块回调均已清空，不会修改设置。体温条通过独立的 SkyUI 初始化路径继续工作。

## 汉化与修复

- 汉化环境提示、食物／衣物确认菜单和寒冷效果名称；保留内部属性、关键字、插件名和表单 ID。
- 修正生命、耐力和魔法扣值时的冰抗公式：零冰抗承受基础扣值，50% 冰抗减半，100% 及以上免除，负冰抗增加扣除量。默认耐力和魔法惩罚会正常扣值，生命惩罚仍关闭。
- 清理停用后遗留的恢复减益；补全取暖动作的按键退出，离开热源或游泳时也会退出，动作启动失败时不会记录为已启动。
- 关闭 Frostbite 的 MCM 注册并清理旧菜单，旧滑块／按钮回调没有设置写入；不修改其他模组的 MCM。

## 验证范围

构建检查 ESL 修改范围、四份实际 Skyrim PEX、固定预设、MCM 注册和设置写入路径，以及 ZIP 内容和哈希。STR 本体没有修改，后台任务仍无阶段并绑定本机玩家。天气读取通用分类，可沿用 Azurite 天气记录。

没有进行 Skyrim 双机游戏实测。编译与静态检查不能代替旧存档菜单缓存移除、实际 HUD、取暖动作和联机扣值的游戏验证。

保留原作者的 Frostbite 代码与界面资源。实际编译源码位于 `scripts/source`，`SHA256.json` 可核对包内文件。
