# STR Missives Board Sync

这是一个全新的 STR 公告板兼容模组，面向提供的 Missives.esp（含中文汉化版）。它使用新建的公告板协议，不包含旧的 `STR_Missives_Compat.esp`，也不传输任务阶段、目标别名、奖励或任务物品。

公告以实体告示板的引用 ID 区分。玩家在某块板接取后，服务器立即从所有玩家对这块板的视图中移除该条告示；其他实体板上的同类任务仍可独立出现和领取。公告书只同步任务/书籍表单标识。只有赢得该板领取请求的玩家会在自己的本地任务上进入接取阶段；其他玩家只移除本地影子公告并停止未领取的影子任务。

## 安装

1. 所有客户端和服务器安装同一版本的 STR 二进制文件。该版本修改网络协议，不能与未打补丁的 STR 混用。
2. 每个客户端安装 `Scripts` 目录中的编译脚本，并保留 `Missives.esp` 原插件及其正常依赖。
3. 不要安装旧的 `STR_Missives_Compat.esp`。

本模组不带 ESP：它不增加任务、容器或脚本属性，只覆盖 Missives 已有的 Papyrus 脚本，并由 STR 原生桥接代码提供网络与过滤逻辑。

## 验证范围

任务表单与公告书索引从提供的 ESP 中提取，仅保留 264 个任务 ID、公告书 ID、公告别名和板别名。任务目标、任务奖励、全局变量和别名实例都不进入目录或网络协议。

源码检查已覆盖脚本触发器与原生注册名的一一对应、每块实体板的领取隔离、任务阶段过滤、个人任务物品过滤和旧协议清理。编译与双客户端游戏内验证需在 Windows Skyrim 环境完成；没有游戏运行时的结果不视为游戏测试通过。
