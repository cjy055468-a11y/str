# STR 原版旅馆租床共享补丁 0.1 测试版

适用范围：原版 `RentRoomScript` 管理的新租约。按你的要求，只处理新租房，所有玩家共享，不限制队伍。布鲁玛及其他自定义租房脚本尚未核查。

## 安装

所有客户端退出游戏，在 MO2/Vortex 安装本 ZIP，让 `Scripts/RentRoomScript.pex` 覆盖原版同名脚本。没有新增 ESP。保留现有 STR 程序和 iNeed 酒醉/睡眠补丁。

若模组管理器显示另一个模组也提供 `RentRoomScript.pex`，请先记录其名称；本包依据原版脚本制作，覆盖自定义租房脚本可能丢失该模组的扩展功能。

## 行为

原版租房以旅馆老板的 `Variable09 = 1` 表示已出租。现有 STR 会同步这个状态，却没有同步床铺主人。本补丁每秒检查当前已加载旅馆老板的出租状态，把该脚本 `Bed` 指向的床在本机授予本机玩家使用。所有参与者安装同版补丁后，有人租房，其他客户端即可使用同一张出租床，无需再次付费，也无需同队。

租金、原版租期和领路流程沿用原版。出租状态变回 0 后，客户端撤销自己发放的共享权限；离开旅馆时撤销访客权限，重新加载旅馆时按当前出租状态重新核对。未出租的床保持原有归属。

## 测试

1. 所有人安装补丁、重启游戏。从新租的一次房间开始测试。
2. 在白漫城由 A 正常付费租房，B 等待约 1 秒后使用出租床。B 应能进入原版睡眠菜单，不再出现“已经租房却不能睡”的情况。
3. 让 B 与 A 不组队，重复检查，仍应共享。
4. B 离开旅馆再返回，仍应按当前出租状态获得权限。另找一张未出租的床，确认它仍保留原来的归属限制。
5. 租约正常到期、出租状态清除后，B 的共享权限也应撤销。租金只在原版购买流程中扣除。

## 验证范围与限制

本包需要编译检查和双客户端游戏内验证。当前环境没有运行 Skyrim 客户端，不能把编译通过当作联机实测通过。

本轮按你的要求不接管旧租约、不迁移旧存档。租约的到期计时仍由实际租房者的原版脚本负责；如果租房者退出游戏，房间何时结束出租仍沿用原版/STR 原有行为，本补丁没有增加服务端租约计时器。共享依据是 STR 已同步到本机的出租状态。
