# STR 原版＋布鲁玛旅馆租床共享补丁 0.1 测试版

一个安装包，同时覆盖原版旅馆和你提供的布鲁玛主插件中沿用原版租房脚本的旅馆。有人付费租房后，所有安装补丁的客户端共享对应床铺的睡眠权限，不限制队伍。

## 安装

所有客户端退出游戏，用 MO2/Vortex 安装本 ZIP，让 `Scripts/RentRoomScript.pex` 覆盖原版同名脚本。没有新增 ESP。继续保留现有 STR 程序、iNeed 酒醉/睡眠补丁，以及你的 `MoreExpensiveInns.esp`。

## 行为与范围

原版以旅馆老板的 `Variable09 = 1` 表示已出租。现有 STR 已同步此状态，本补丁每秒检查当前已加载旅馆老板的出租状态，把脚本 `Bed` 属性所指床铺在本机授予本机玩家使用。

房间出租状态清除后，撤销本机共享权限；访客离开旅馆时撤销本机权限，重新加载旅馆时再次按当前出租状态核对。租金、原版租期和领路流程沿用原有调用。

本轮按你的要求只处理新租约，不接管旧租约或迁移旧存档。

## 布鲁玛检查

你提供的 `BSHeartland.esm` 中，7 个 NPC 绑定原版 `RentRoomScript` 和原有 `Bed`、`WI` 属性，共6张出租床，因此和原版共用同一个 PEX，无需另加布鲁玛 ESP。租房对话也用 `Variable09` 的0/1区分可租和已租。

已核验 `MoreExpensiveInns.esp` 将 `Skyrim.esm:0009CC98` 的 `RoomCost` 设为50。布鲁玛的 `CYRGenericDialogue.RoomRentalCost` 引用同一变量。本包不包含费用插件，保留现有价格模组的结果。布鲁玛有一条租房文字写死了10金币，显示可能仍为10；本次不改费用或文字。

## 双端测试

1. 所有人安装同一包，重启游戏。从新租的一次房间开始。
2. 在白漫城由 A 正常付费租房，保持出租床空闲；B 等待约1秒，再使用同一张床，应能进入原版睡眠菜单。
3. A、B 不组队时重复检查，仍应共享。
4. B 离开旅馆再回来，仍应按当前出租状态获得权限；另查一张未出租的床，确认原来的归属限制仍然存在。
5. 在布鲁玛的旅馆重复上述流程，例如 CYRBrumaJerallViewPlayerBed 或 CYRRestfulWatchmanPlayerBedRef 对应的出租房。
6. 原版租约正常到期、出租状态清除后，B 的共享权限也应撤销。结合 iNeed 睡眠补丁，测试实际睡眠后疲劳是否恢复。

## 已完成的检查

Windows 上使用固定版本 Caprica 编译为 Skyrim PEX 3.2；原版 `Bed/WI` 属性、租金读取、租期登记和领路调用均保留。已检查脚本接口、安装包结构和布鲁玛插件绑定。

当前环境没有运行 Skyrim 客户端，因此尚未完成双客户端游戏内测试，编译通过不代表已联机实测。

租约到期计时仍由实际租房者的原版脚本负责；租房者退出游戏后的到期行为沿用现有原版/STR机制。本包没有新增服务端租约计时器，共享依据是 STR 已同步到本机的出租状态。
