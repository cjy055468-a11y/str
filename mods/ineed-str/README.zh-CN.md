# iNeed × STR 整合覆盖包 0.3（隐藏 MCM）

适用于 Skyrim 1.6.1170、你上传的 iNeed Continued 1.95，以及当前 STR `v1.8.4-coopfix4g-corpse5-state1s-loot2-notice-board-v2-r1`。

## 安装

1. 退出游戏，在 MO2/Vortex 停用旧的 needstr 兼容补丁和单独的 MCM 默认设置补丁，然后安装本压缩包。
2. 保留基础 iNeed 和现有 SKSE、SkyUI、STR。本包覆盖 iNeed 的同名插件与相关脚本。
3. 启用 `iNeed.esp`、`iNeed_STR_Compatibility.esp`，兼容插件放在 iNeed 后。本包优先覆盖基础 iNeed。
4. 所有玩家安装相同版本；服务器程序继续使用当前版本。原有旅馆同步补丁可继续保留。
5. 启动游戏即可自动应用下列设置，不需要进入 MCM、使用控制台或重新生成动作。

## 已固定的设置

| 设置 | 默认值 |
| --- | --- |
| 吃喝动画 | 开启，含站立和坐姿 |
| 强制摄像机 | 开启，沿用 iNeed 的强制第三人称逻辑 |
| 有价值的农作物 | 开启，保留采收权限及对话逻辑 |
| 食物腐败 | 开启，自动启动原有腐败任务 |
| 腐败显示 | 原版 Numbers 模式，即新鲜度百分比，例如食物名后面的 `80%` |
| iNeed MCM | 整个菜单隐藏，iNeed 功能继续运行 |

百分比表示剩余新鲜度/食用价值，数值越低表示腐败越重。腐败速度沿用原版 iNeed 的设置，特殊食物仍遵循原本规则。

隐藏菜单采用 iNeed 自身的 SkyUI 注册事件覆盖，只移除 iNeed 这一项。保留原配置任务、快捷键处理和其它模组的 MCM。菜单刷新时也不会重新注册 iNeed。SkyUI 正在处理菜单时会按原有就绪事件重试。

## 保留的兼容修复

- 吃喝动画同步：A 吃喝，B 在 A 的远程角色上看到动作。你已经反馈 v0.2 的这一项实测可用；本包原样保留该版 ESP 及全部六个运行脚本，并按 SHA-256 核对。
- 酒醉：喝酒者自己的画面和踉跄由其本机处理，保持原参数及属性惩罚。
- 睡眠：按原版睡眠事件和“累计睡眠小时”的实际增量恢复疲劳，保留 iNeed 原恢复公式；不调整 STR 世界时间。
- 原版主脚本的中文文本及所有函数体原样保留，只补入“动画开启”和“腐败开启”的初始值。强制摄像机、数字显示原本已开启，继续保留。
- `iNeed.esp` 只调整两个有价值农作物的默认全局变量；兼容 ESP 不新增修改。

## 检查与首次验证

已执行编译、PEX 结构及绑定核对、原文件精确还原验证和旧兼容文件逐字节比较。隐藏 MCM、自动启动腐败及新默认组合尚未在本环境运行游戏验证；现有动画同步的通过结论来自你的 v0.2 实测。

按之前约定，以新存档确认初始默认设置。加载后应找不到 iNeed MCM，但 iNeed 饥渴和疲劳继续运行；站立吃喝自动播放且可同步。新取得的可腐败食物按原版刷新后应出现百分比，数值按原版时间和腐败规则变化。其余特殊食物依旧适用原版分类。

启用 Papyrus 日志后可搜索：

- `[iNeed-STR] preset:`：确认默认值及腐败任务启动结果。
- `[iNeed-STR] iNeed MCM hidden`：确认只注销了 iNeed 菜单。
- `[iNeed-STR] consume`：原有动画同步日志继续保留。

不处理旧存档脚本迁移，不调整租金或寒冷模组，也不更换 STR 客户端及服务器。
