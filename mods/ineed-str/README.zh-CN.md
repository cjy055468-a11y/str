# iNeed × STR 酒醉与睡眠兼容补丁 0.1 测试版

适用：Skyrim 1.6.1170、你上传的 iNeed Continued 1.95，以及现有 STR `v1.8.4-coopfix4g-corpse5-state1s-loot2-notice-board-v2-r1`。这是独立 ESP 与脚本覆盖包，所有玩家安装同一份。服务器程序保持现有版本。

## 安装

1. 退出游戏；在 MO2/Vortex 安装本压缩包。
2. 保留原 iNeed。让补丁覆盖原脚本，并将 `iNeed_STR_Compatibility.esp` 排在 `iNeed.esp` 后。
3. 启用补丁，重新启动游戏。原 STR、SKSE、iNeed 依赖继续使用现有版本。

## 本次修改

- 酒醉画面只由喝酒者本机的玩家效果控制。远程玩家喝酒或醒酒，都不再调用本机画面效果。醉酒属性数据、饮酒判定和原画面参数保持不变；踉跄物理由喝酒者本机处理。
- 使用原版 `OnSleepStart`、`OnSleepStop` 事件。在开始时记下“累计睡眠小时”，结束时按统计差额恢复 iNeed 疲劳。世界时间继续由 STR 控制。选择 8 小时、实际完成 3 小时后中断，按 3 小时计算，不按预选 8 小时计算。
- 恢复公式保留 iNeed 的每小时恢复量、床卷/危险地点/疾病/饥渴修正、随机变化与吸血鬼/狼人分支。不会用预选小时冒充实际完成小时。
- 本轮按你的要求只做酒醉和睡眠；吃喝动画同步留到下一轮。

## 请测试

1. A 连续喝酒直到醉酒；B 保持清醒。A 应有原来的画面效果、属性惩罚和踉跄；B 的画面、属性不应变化。
2. A、B 同时醉酒，然后只让 B 醒酒。A 的醉酒画面不应被 B 的醒酒移除。
3. 先记录疲劳与游戏时间，正常睡 3 小时。疲劳应按 iNeed 公式恢复，联机时间不应跳 3 小时。
4. 选择 8 小时，在完成 3 小时后中断。只按实际 3 小时恢复。直接取消选时界面不恢复。
5. 单独按 T 等待不算睡眠；一人睡眠不恢复其他人的疲劳。

编译与结构检查不能替代双客户端游戏内测试。本环境没有运行 Skyrim 游戏客户端。

睡眠核对：游戏统计菜单“累计睡眠小时”应增长实际完成小时。启用 Papyrus 日志时，可搜索 `[iNeed-STR] sleep completed=`；例如 `completed=3 requested=8 interrupted=True`。如果该统计在你的客户端没有增长，本版不会冒用预选时长发放恢复，请提供这条日志和统计前后值。

现有存档已经生效的旧酒醉脚本可能继续运行到旧效果结束。首次测试请从未醉酒的存档开始；这是替换效果脚本的存档限制。
