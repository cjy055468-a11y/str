# iNeed Continued 1.95 默认设置覆盖包

按本次要求设置三个默认项：

- 吃喝动画：开启（站立和坐下都允许播放，选项索引2）。
- 强制摄像机：开启。上传原包的底层默认值已为开启，本包保留该值。
- 有价值的农作物／有价值的收获：开启，同时开启其农场主对话开关。

MCM 继续保留，之后仍可在游戏中手动调整。这是初次初始化的默认设置。

## 安装

保留原 iNeed，用 MO2/Vortex 安装此 ZIP，让它覆盖原 iNeed 的 `iNeed.esp` 及两个同名脚本。没有新增插件名称，继续启用原来的 `iNeed.esp`。

如果已经安装本次会话制作的 iNeed 酒醉／睡眠兼容补丁，继续保留；本包不包含该兼容补丁的三个脚本或其独立 ESP。

## 检查

已核对 MCM 初始化读取路径与实际运行脚本：动画默认属性、MCM 动画初始值及菜单的恢复默认索引均为2；强制摄像机保持True；农作物及其对话的两个全局默认值均为1，MCM 对应初始开关为True。

修改以原始 PEX 的类型化默认值和一个菜单默认参数为单位，保留其他函数内容。`validation.json` 记录每一处修改前后的字节及哈希，可准确还原上传原件。原 `iNeed.esp` 只修改两个农作物开关的默认值。

另用 Champollion v1.3.2 独立读取修改前后的 PEX，核对反汇编仅有4行语义差异：三个初始值与一个动画菜单默认参数；摄像机默认True保持原样。

尚未运行 Skyrim 客户端。请新开一局或首次初始化 iNeed 后检查这三个 MCM 默认项；本包不在每次读档时强制覆盖你之后手动选择的设置。
